# 🎯 AliFilter - 알리익스프레스 정밀 검색 & 스마트 가격 필터 (v3.0)

> **알리익스프레스 검색 시 엉뚱한 연관 상품, 옵션 낚시, 광고에 지친 쇼퍼들을 위한 크롬 확장 프로그램!**  
> 사용자가 검색한 검색어 중 **"진짜 필수 키워드가 모두 들어간 상품"**만 골라 보여주고, 핵심 단어 **형광펜 하이라이트** 및 **실시간 스마트 가격 필터**를 제공합니다.

---

## 🚀 핵심 기능 (v3.0)

1. **💰 실시간 스마트 가격 필터 (알리 왼쪽 필터 버그 완벽 해결)**
   - 알리 왼쪽 필터처럼 페이지가 새로고침되거나 검색어가 꼬이지 않는 **0.01초 실시간 필터**!
   - **직접 입력**: `[최소 금액] ~ [최대 금액]` 입력 후 `[적용]`
   - **원클릭 퀵 프리셋 칩**: `[~5천원]` `[~1만원]` `[1만~3만원]` `[2천원↑(낚시컷)]` `[↺ 초기화]`
   - **옵션 낚시 컷오프**: 5만원짜리 물건에 400원짜리 나사못 끼워 파는 낚시 매물을 하한선(예: 2천원 이상)으로 한 방에 박멸!

2. **✨ 스마트 키워드 하이라이트 & 유연 매칭**
   - 띄어쓰기나 하이픈이 달라도 똑똑하게 감지합니다:
     - `type-c` 검색 ➔ `Type-C`, `Type C`, `typec` 모두 완벽 일치 및 하이라이트!
     - `esp32-c3` 검색 ➔ `ESP32 C3`, `ESP32-C3`, `ESP32C3` 모두 일치!
     - `65w` 검색 ➔ `65W`, `65 W` 모두 일치!
   - `가성비`, `추천`, `좋은` 같은 일반 수식어는 스마트 분리되어 기본 필터에서 안전하게 제외됩니다.

3. **🚫 엄격한 필수 키워드 필터링 (AND 조건)**
   - 지정된 필수 키워드가 **전부(AND)** 들어있는 진짜 상품만 통과시킵니다.
   - **3가지 필터 모드**: `[🚫 완전 숨김]`, `[👻 반투명 흐리게]`, `[✨ 강조만]`

4. **💊 스마트 컴팩트 알약 바 & 단축키 (Alt + F)**
   - 평소에는 화면 우측 상단에 얇고 세련된 **알약 바(`🎯 알리 필터 | 3/9 통과 | ~5,000원 | [숨김]`)**로 조용히 위치합니다.
   - 클릭하면 전체 패널이 펼쳐지고, 패널 밖을 누르면 다시 알약 바로 컴팩트하게 접힙니다. (핀 `📌` 고정 지원)
   - 키보드로 `Alt + F` (Mac: `Option + F`)를 누르면 언제든지 필터를 0.1초 만에 On/Off 할 수 있습니다.

5. **🛡️ 스폰서 / 광고 상품 자동 차단 (Ad Blocker)**
   - "Sponsored / Ad" 광고 상품을 자동으로 감지하여 차단합니다.

## 📦 크롬에 설치 및 업데이트 방법 (30초 소요)

1. **크롬 브라우저** 주소창에 다음 주소를 입력합니다:
   ```text
   chrome://extensions
   ```
2. 우측 상단의 **`개발자 모드` (Developer mode)**가 켜져 있는지 확인합니다.
3. 처음 설치하신다면:
   - 좌측 상단 **`압축해제된 확장 프로그램을 로드합니다`** 클릭 ➔ `C:\AI\Chrome\aliexpress` 폴더 선택
4. 이미 설치해 두셨다면:
   - `AliFilter` 카드의 **새로고침(🔄) 아이콘**을 클릭하면 즉시 최신 v3.0 코드가 반영됩니다!
