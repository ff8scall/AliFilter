# 프로젝트 메모리 (MEMORY.md)

## 1. 현재 진행 상황
- **작업명**: AliFilter 제휴 혜택 & 핫딜 추천 탭 (쿠폰 안내 & 5성급 핫딜 큐레이션 및 트래킹 ID 연동) 완료
- **상태**: Phase 1 ~ Phase 7 전 항목 완료 및 코드 컴파일/문법 검증 완료
- **최신 성과**:
  - **100% 합법적 수익화 모델 구현**:
    - 쿠키 스터핑이나 납치 없이 사용자가 직접 원해서 누르는 윈-윈(Win-Win) 구조 확립.
    - 사용자 본인의 트래킹 ID(`alifilter`) 및 제휴 링크(`https://s.click.aliexpress.com/e/_c3OgBvzx`) 연동.
  - **서브 탭 네비게이션 탑재 (`[🔍 정밀 필터]` / `[🎁 혜택 & 핫딜]`)**:
    - 플로팅 패널 상단에 원클릭 전환 탭 바 및 'HOT' 뱃지 적용.
  - **이달의 프로모션 코드 & 원클릭 복사**:
    - 알리 공식 할인 코드 목록 노출 및 클릭 즉시 클립보드 복사 + '복사됨!' 피드백.
  - **AliFilter 검증 5성급 핫딜 카드**:
    - 평점 4.8+, 수만 건 판매 검증 인기 상품 큐레이션 및 '특가 보러가기' 제휴 링크 연결.
  - **데이터 파일 모듈 분리 (`scripts/promotions.js`)**:
    - 추후 사용자가 언제든지 코드와 링크, 상품명을 쉽게 수정/추가할 수 있도록 데이터 완벽 분리.
  - **실시간 한/영(KO/EN) 2개 국어 완벽 연동**:
    - 언어 전환 시 혜택 탭 타이틀, 버튼, 카드 설명, 고지 문구가 즉시 실시간 전환.
  - **투명성 고지 (FTC & 웹스토어 정책 100% 준수)**:
    - 하단에 제휴 링크 안내 문구 표기.

## 2. 사용 가이드
- 브라우저의 `chrome://extensions`에서 새로고침 후 즉시 사용 가능.
- 추후 핫딜이나 쿠폰을 바꾸고 싶으실 때는 `scripts/promotions.js` 파일만 열어서 내용이나 링크를 수정하시면 됩니다.
