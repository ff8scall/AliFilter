# 프로젝트 메모리 (MEMORY.md)

## 1. 현재 진행 상황
- **작업명**: 핫딜 실제 상품 링크 연결 & 위젯 2-Tab 간소화 (쿠폰 결함 제거)
- **상태**: 100% 정상 작동 검증 및 깃 원격 푸시 완료 (`main` 브랜치)
- **최신 성과**:
  1. **핫딜 클릭 시 실제 알리 상품 페이지로 직행**:
     - 기존에 8개 핫딜 상품이 전부 알뜰마트 제휴 홈으로 연결되던 치명적 문제 해결.
     - AULA F75, Baseus 65W, QCY T13 ANC 등 8종 상품 클릭 시 해당 알리 공식 검색/상세 페이지로 즉시 이동.
  2. **위젯 2개 탭 구조로 단순화 (`정밀 필터` + `5성급 핫딜 & 특가`)**:
     - 선착순 만료/오류로 결제 시 적용 불가하던 무의미한 프로모션 코드 탭을 완전히 제거하여 사용자 신뢰 회복.
     - 상단 네비게이션을 2개 탭으로 재편하여 클릭 영역 확대 및 UI 가독성 대폭 향상.
  3. **알뜰마트 특가전 배너 핫딜 탭 상단 배치**:
     - "초이스 알뜰마트 & 골라담기 특가전"을 핫딜 탭 최상단에 명확하게 배치하여, 사용자가 알뜰마트 특가 혜택(3개 $5.99~)을 원할 때만 명확히 인지하고 클릭할 수 있도록 정직하게 UI 개선.
  4. **원격 동기화 유효성 검사 로직 정상화**:
     - `scripts/promotions.js`의 `isValidPromotions`에서 빈 쿠폰 배열 지원(`hotdeals.length > 0` 검증).

## 2. 사용 가이드
- 브라우저의 `chrome://extensions`에서 **AliFilter '새로고침(↻)'** 버튼을 클릭한 뒤, 알리익스프레스 페이지를 새로고침(F5)하시면 즉시 적용됩니다:
  1. `[🔍 정밀 필터]`: $50~$106 설정 시 할인율(-54%)에 속지 않고 $115, $130, $249 등 고가 상품이 완벽하게 필터링됩니다.
  2. `[🔥 5성급 핫딜 & 특가]`: 카드의 [특가 보러가기]를 누르면 AULA F75 등 실제 해당 상품 페이지가 새 탭에서 바로 열립니다.
