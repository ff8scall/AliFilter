# 프로젝트 메모리 (MEMORY.md)

## 1. 현재 진행 상황
- **작업명**: 가격 필터 할인율 퍼센트(-54%, -51%) 오인식 버그 근본 수정 완료
- **상태**: 버그 원인 분석, 정밀 파서 구현, 9종 상품 데이터 검증 및 깃 푸시 완료
- **최신 성과**:
  - **할인율 퍼센트 오인식 버그 완전 박멸**:
    - `-54% us $115.95`에서 앞쪽 할인율 숫자 `54`를 상품 가격으로 오인식하여, $50~$106 필터 설정 시 $249, $115, $130 등의 고가 상품이 통과되던 치명적 결함 발견 및 해결.
    - `parsePrice`에서 할인율 퍼센트(`-54%`, `50%` 등)를 선제 제거하고, 실제 통화 기호(`US $`, `$`, `₩`, `원`) 뒤에 오는 실제 판매가만 정확히 추출하도록 전면 개편.
  - **정가(취소선) 배제 및 우선순위 강화**:
    - `getCardPrice`에서 `del`, `strike`, `original` 요소 배제 및 판매가 전용 셀렉터 우선 검색 적용.
  - **9개 스크린샷 상품 검증 100% 통과**:
    - $74.69, $100.61, $65.81, $73.63, $73.25 -> 정상 노출 (PASS)
    - $249.92, $115.95, $130.89, $129.05 -> 예산 초과로 정확히 숨김 처리 (HIDE)

## 2. 사용 가이드
- 브라우저의 `chrome://extensions`에서 AliFilter 새로고침 후, 알리익스프레스 검색 페이지를 새로고침(F5)하시면 $50~$106 설정 시 $115, $130, $249 등의 고가 상품이 즉시 깔끔하게 사라집니다!
