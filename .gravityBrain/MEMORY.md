# 프로젝트 메모리 (MEMORY.md)

## 1. 현재 진행 상황
- **작업명**: 3단 탭(필터/쿠폰/핫딜) 분리 및 카테고리별 핫딜 셔플 큐레이션 구축 완료
- **상태**: Phase 1 ~ Phase 4 전 항목 완료 및 컴파일/문법 검증 완료
- **최신 성과**:
  - **3단 독립 서브탭 개편 (`[🔍 정밀 필터]` / `[🎟️ 할인 쿠폰]` / `[🔥 5성급 핫딜]`)**:
    - 스크롤 부담을 없애고 콘텐츠 집중도 300% 향상.
    - 탭 전환 시 부드러운 인플레이스 화면 전환 및 HOT 뱃지 유지.
  - **5성급 핫딜 카테고리별 퀵 칩 (`[전체]` / `[⚡ 충전/케이블]` / `[🖱️ PC/주변기기]` / `[🎧 음향/이어폰]` / `[🚗 차량/생활]`)**:
    - 사용자가 관심 있는 카테고리만 원클릭으로 필터링하여 검증된 핫딜 탐색.
  - **`🎲 다른 핫딜 추천 (새로고침)` 랜덤 셔플 엔진 탑재**:
    - 버튼 클릭 시 핫딜 풀(Pool)이 순환 회전하며 새로운 추천 상품을 동적으로 교체 노출.
    - 호기심을 자극하여 사용자의 지속적인 탐색과 제휴 링크 클릭률 극대화.
  - **쿠폰 탭 분리 집중**:
    - 전회원 공식 쿠폰팩 수령 배너 + 알리 공식 프로모션 코드 목록 + 원클릭 복사 기능이 깔끔하게 독립.

## 2. 사용 가이드
- 브라우저의 `chrome://extensions`에서 새로고침 후 즉시 사용 가능합니다.
- 알리 검색 화면에서 상단 3개 탭을 번갈아 클릭하며 필터/쿠폰/카테고리별 핫딜 셔플을 즐길 수 있습니다.
